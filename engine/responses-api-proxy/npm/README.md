# @openai/hexa-responses-api-proxy

<p align="center"><code>npm i -g @openai/hexa-responses-api-proxy</code> to install <code>hexa-responses-api-proxy</code></p>

This package distributes the prebuilt [Codex Responses API proxy binary](https://github.com/openai/codex/tree/main/engine/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/hexa-responses-api-proxy.js --help
```

Refer to [`codex-rs/responses-api-proxy/README.md`](https://github.com/openai/codex/blob/main/engine/responses-api-proxy/README.md) for detailed documentation.
