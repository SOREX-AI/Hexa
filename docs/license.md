The repository contains components under separate licenses; it does not offer a choice of license for the same code. The upstream Codex engine is licensed under the [Apache License 2.0](../LICENSE-APACHE-2.0), while Hexa's Electron shell is licensed under [GNU GPL v3.0 only](../LICENSE-GPL-3.0).

When distributing a Hexa binary, provide the complete corresponding source for the GPL-covered shell, including the scripts needed to build and install it, in accordance with GPLv3 section 6. Keep the engine's Apache-2.0 license and the repository [NOTICE](../NOTICE) with the distribution.
